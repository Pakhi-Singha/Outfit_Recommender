# Outfit_Recommender

Pink Outfit Recommender Web App 🎀👗

A cute, pink-themed web application that helps users choose the perfect outfit based on dress code — Cocktail or Corporate. Built with Python and Flask, it displays clothing item recommendations (with images) pulled from a virtual closet.
It combines a Python backend with HTML/CSS (Bootstrap) and image rendering for a fun, visual user experience.

## ✨ Features

- 🎀 Dropdown selection for "Cocktail" or "Corporate"
- 👗 Outfit recommendations based on selected dress code
- 🖼️ Each item has a name, category, and image
- 🌸 Pink-themed design using Bootstrap

## 🛠️ Setup Instructions

1. **Clone the repository**
    ```bash
    git clone https://github.com/yourusername/pink-outfit-recommender.git
    cd pink-outfit-recommender
    ```

2. **Install Flask**
    ```bash
    pip install flask
    ```

3. **Run the app**
    ```bash
    python app.py
    ```

4. **Open in browser**
    ```
    http://127.0.0.1:5000
    ```
